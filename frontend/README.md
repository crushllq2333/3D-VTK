实现的是渐变映射。

后端，会将点的强度值归一化到 [0,1] 范围，再通过matplotlib.cm的色图（如viridis）映射为 RGB 颜色。viridis等色图的颜色是连续渐变的，并非按固定区间进行分区映射，每个不同的归一化值都会对应色图中相应位置的颜色，从而形成平滑的颜色过渡。

前端中，当存在标量数据时，创建了颜色传输函数vtkColorTransferFunction，并在标量值的最小值、中间值和最大值处分别设置了蓝色、绿色和红色，这也会使颜色在整个标量范围内呈现出从蓝色到绿色再到红色的连续渐变效果，而非分区映射那种不同区间呈现固定单一颜色的方式。
